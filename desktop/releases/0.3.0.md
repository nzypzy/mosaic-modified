# Mosaic 0.3.0

First release of this modified copy of Mosaic Desktop. The original app and its author are credited in `NOTICE.md`.

## Claude for every AI feature

- Ask Echo and all AI features now run on Claude through the Claude Code CLI installed on this PC, using its existing sign-in. No API key is needed or used.
- Each feature uses a fitting model: Sonnet for chat, meeting minutes, summary refinement, notes drafting and IT Projects; Haiku for quick extraction such as meeting details, topic discovery and task suggestions.
- Ask Echo reads the Mosaic data folder and can only save files into its `Outputs` folder, so records cannot be changed by the assistant.

## ClickUp (read-only)

- New ClickUp page with the open tasks of the Lists you add: status, assignee, due date, priority, overdue highlight, filters and search.
- Dashboard panel with In progress and To do tasks, and ClickUp due dates and start-to-due timelines on the Dashboard calendar.
- Request-saving sync: one request every 10 minutes checks all Lists for changes; a full pull runs each morning and on Sync now.
- "As of" status with Sync now, plus desktop notifications for new tasks, status changes and tasks due within a day.
- The personal API token is entered in Settings and stored encrypted with Windows secure storage.

## Appearance

- Light, Dark and Follow Windows themes in Settings, plus a quick light/dark switch in the status bar. Dark stays the default.
- The Dashboard calendar opens on the current month.

## Fixes

- New IT project and Notebook's Add link no longer crash (the desktop app does not support browser prompt pop-ups).
- Links to other sites open in the default browser instead of replacing the Mosaic window.
- Stopping the development server no longer empties an installed package, which caused "Can't resolve 'rimraf'".
- The data folder is now named Mosaic Data.
