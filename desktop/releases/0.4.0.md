# Mosaic 0.4.0

## IT Projects: General and Development types

- Choose a project type when you create a project: **General** (Overview with timeline, Tasks / action items, Reports) or **Development** (the full delivery layout: Product and Sprint backlogs, RTM, System Design, End-to-End Process, Deployment).
- Change a project's type any time from the **Type** menu. Data from both types is kept; only the visible sections change.
- General projects have their own phases (Initiation, Planning, Execution, Monitoring & Control, Closure), a task list with owner, due date, status, priority and notes, and their own workbook export and document drafts (Project Charter, Status Report, Project Closure Report).
- Projects created before this release open as Development projects, unchanged.
- Project cards show each project's type.

## Fixes

- List view in IT Projects tables now includes the name column (previously only editable in Cards view).
- Updated tests for IT Projects, the meeting summary editor and the Ask Echo panel so the whole test suite runs and passes.
